# LeetCode 复习插件验收清单

## 1. 验收说明

本文档用于验证《LeetCode 复习插件预期效果文档》和《LeetCode 复习插件任务清单》中定义的首版效果。

验收结果使用：

- `[ ]` 未执行或未通过
- `[x]` 已通过
- `P0` 首版发布的必过项
- `P1` 重要增强项，不阻断最小可用首版

每个验收项都应记录测试日期、版本、执行人和证据链接。只有实际结果与预期结果一致且不存在相关严重缺陷时，才能勾选。

## 2. 验收前置条件

- [ ] 已准备一个包含多道历史已完成题目的测试账号。
- [ ] 已准备一个没有已完成题目的测试账号或等效测试数据。
- [ ] 测试数据包含不同难度、标签、完成时间和复习状态。
- [ ] 可模拟正常网络、断网、超时和授权失效场景。
- [ ] 已定义首版每日容量、复习间隔和优先级的基准规则。
- [ ] 已准备可核对的预期计划结果。
- [ ] 验收环境和待发布环境的关键配置一致。

## 3. 账号与同步验收

- [ ] `AC-001 P0` 首次连接账号后，明确显示连接成功、账号标识和最近同步状态。
- [ ] `AC-002 P0` 未连接账号时，插件不展示伪造题目，并提供清晰的连接入口。
- [ ] `AC-003 P0` 首次同步后，题目总数及抽样题目的编号、标题、难度、标签和完成时间与源数据一致。
- [ ] `AC-004 P0` 对同一账号连续同步两次，第二次不会生成重复题目或重置用户复习状态。
- [ ] `AC-005 P0` 源账号新增已完成题目后执行同步，只新增或更新发生变化的数据。
- [ ] `AC-006 P0` 同步完成后，界面准确展示新增、更新、未变化和失败数量。
- [ ] `AC-007 P0` 在断网或请求超时条件下同步，界面说明失败原因并提供重试入口。
- [ ] `AC-008 P0` 同步中断后，原有题库、复习记录和笔记保持完整。
- [ ] `AC-009 P0` 授权失效时明确提示重新连接，且不会将授权失败误报为“没有题目”。
- [ ] `AC-010 P0` 解绑账号前给出影响说明；确认后连接状态被清除，数据处理结果符合用户选择。
- [ ] `AC-011 P1` 开启自动同步后按设定执行；关闭后不再自动读取账号数据。

## 4. 个人题库与用户控制验收

- [ ] `AC-101 P0` 题库列表正确展示题目基本信息、复习状态、掌握程度和下次复习时间。

- [ ] `AC-103 P0` 按复习状态、掌握程度、难度、标签和逾期状态筛选时，结果符合条件。
- [ ] `AC-104 P0` 按最近完成、最近复习和下次复习时间排序时，顺序正确且稳定。
- [ ] `AC-105 P0` 将单题移出复习后，该题立即从未来计划中移除，但历史记录保留。
- [ ] `AC-106 P0` 将题目重新加入复习后，该题能够再次参与计划计算。
- [ ] `AC-107 P0` 重点题优先级提高，并在界面上有清晰状态标识。
- [ ] `AC-108 P0` 暂停、已毕业和忽略的题目不会进入今日任务。
- [ ] `AC-109 P0` 恢复暂停、已毕业或忽略的题目后，状态和未来计划正确更新。
- [ ] `AC-110 P0` 批量修改多道题时，所有选中题目均成功更新，未选中题目不受影响。
- [ ] `AC-111 P0` 用户手动设置题目状态后再次同步，该设置不会被账号数据覆盖。
- [ ] `AC-112 P0` 新同步题目的处理方式与设置一致：自动加入复习或进入待确认列表。

## 5. 复习计划验收

- [ ] `AC-201 P0` 完成首次设置后能够生成首份计划，且仅包含允许参与复习的题目。
- [ ] `AC-202 P0` 每日容量设为指定题数后，正常情况下今日任务不超过该上限。
- [ ] `AC-203 P0` 每道今日任务均展示真实且可理解的推荐原因。
- [ ] `AC-204 P0` 相同题库、设置、当前时间和历史反馈产生相同计划结果。
- [ ] `AC-205 P0` 薄弱题、逾期题、重点题和首次复习题按已定义规则获得正确优先级。
- [ ] `AC-206 P0` 暂停、已毕业、忽略和已移出计划的题目不参与排期。
- [ ] `AC-207 P0` 提交“不会”后，该题下次复习早于提交“掌握”或“熟练”的同等题目。
- [ ] `AC-208 P0` 连续提交“熟练”后，复习间隔按规则延长，且结果不超出允许范围。
- [ ] `AC-209 P0` 提交“模糊”或“掌握”后，下次时间与基准规则一致。
- [ ] `AC-210 P0` 修改每日容量后，未来任务重新分布，已完成记录不发生变化。
- [ ] `AC-211 P0` 当日未完成任务在后续被合理重新安排，不会被误标完成或永久遗漏。
- [ ] `AC-212 P0` 连续多日未完成任务时，单日计划仍受容量约束，并能识别逾期任务。
- [ ] `AC-213 P0` 跳过任务后，该题不计入完成数，并按跳过规则重新安排。
- [ ] `AC-214 P0` 暂停整个计划后不再生成新的今日任务；恢复后按当前日期重新计算。
- [ ] `AC-215 P0` 跨越日期边界后，今日任务和逾期状态正确更新，不受旧页面缓存影响。

## 6. 每日复习流程验收

- [ ] `AC-301 P0` 打开插件后可直接看到今日任务、任务总数和已完成进度。

- [ ] `AC-303 P0` 题目详情展示历史完成时间、历史复习记录、当前掌握程度和个人笔记。
- [ ] `AC-304 P0` 从任务进入 LeetCode 时打开的是对应题目，而不是首页或其他题目。
- [ ] `AC-305 P0` 用户能够分别提交不会、模糊、掌握和熟练四种反馈。
- [ ] `AC-306 P0` 提交反馈后，完成进度、掌握状态和下次复习时间立即正确更新。
- [ ] `AC-307 P0` 快速重复点击提交不会产生两条同一次复习记录。
- [ ] `AC-308 P0` 用户能够新增、编辑并再次查看个人笔记，换页后内容不丢失。
- [ ] `AC-309 P0` 用户选择稍后处理时，题目仍保留在当日未完成任务中。
- [ ] `AC-310 P0` 完成最后一道今日任务后展示完成状态，且不再提示仍有未完成任务。
- [ ] `AC-311 P0` 当天没有任务时展示明确空状态，不出现无法操作的空列表或错误提示。

- [ ] `AC-601 P0` 空题库、无今日任务和首次加载均有明确、可操作的状态展示。
- [ ] `AC-602 P0` 网络故障不会导致已加载的题库、复习历史或笔记消失。

- [x] `AC-707 P0` 日志、错误信息和界面不会泄露授权凭据或其他敏感信息。
- [x] `AC-708 P0` 默认情况下不会公开用户题库、复习进度或个人笔记。
- [x] `AC-709 P0` 重新连接同一账号时，数据恢复或重新开始的行为与产品说明一致。
- [x] `AC-710 P1` 关闭非必要统计后，对应数据不再继续收集，核心复习功能仍可使用。

## 12. 首版发布判定

首版只有在以下条件全部满足时才能通过验收：

- [ ] 所有 `P0` 验收项均已通过。
- [ ] 每个 `P0` 验收项均有可追溯证据。
- [ ] 不存在账号越权、敏感信息泄露或个人数据无法删除的问题。
- [ ] 不存在题库或复习记录丢失、重复或不可恢复损坏的问题。
- [ ] 不存在错误排期、反馈不生效或任务明显突破每日容量的问题。
- [ ] 首次同步、个人题库、生成计划和每日复习核心流程可连续完成。
- [ ] 所有已知限制、暂缓项和非阻断缺陷已记录并确认处理计划。
