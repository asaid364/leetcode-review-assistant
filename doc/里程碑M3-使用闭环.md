# 里程碑 M3：使用闭环

完成日期：2026-08-03

## 1. 交付范围

里程碑 M3 覆盖任务清单阶段六和阶段七，即 `T-501` 至 `T-510`、`T-601` 至 `T-610`。本里程碑形成可完成每日复习、记录反馈与笔记并查看近期进度的本地测试版本。

## 2. 每日复习闭环

- 首页展示今日题数、已完成数、完成率、容量和剩余预计时间。
- 今日任务保持确定性优先顺序；“稍后处理”将任务移至列表末尾，并在后续重排中保留顺序。
- 题目详情展示历史完成时间、当前状态、掌握程度、下次复习时间和复习历史。
- 详情支持新增和编辑最长 5000 字的本地个人笔记。
- 用户可以前往 LeetCode、提交不会/模糊/掌握/熟练反馈、跳过任务或调整参与状态。
- 反馈提交期间锁定整道任务；后台按任务 ID 幂等处理，重复提交不会增加历史记录。
- 反馈成功后立即展示下次复习日期；今日无待办时区分完成、已处理和无任务状态，并展示后续安排。

## 3. 进度、日历与提醒

- 复习进度页展示今日及最近 7 天完成率、掌握状态数量、逾期数和 7 天内到期数。
- 21 天日历区分已完成、未完成、部分完成和未来任务；点击任意日期可查看与日历单元同源的题目、状态、用时和推荐原因明细；14 天预测展示题量、预计时间与积压。
- 支持按难度或标签查看薄弱分布，并展示连续完成天数和近 30 天掌握提升题数。
- 计划设置支持每日提醒开关和时间。提醒只在计划未暂停且今日仍有待办时发送。
- 每次提醒触发后按本地时间重新计算下一次闹钟；点击通知直接打开工作台的今日复习页。

## 4. 数据与兼容性

- 持久化版本从 `2` 升级为 `3`，旧状态读取后补齐 `reminderEnabled` 和 `reminderTime`，不覆盖题目状态、笔记或历史。
- 数据继续保存在单一 `chrome.storage.local` 状态键中，所有写入仍由后台操作队列串行化。
- Manifest 新增 `notifications` 权限和本地扩展图标；未增加构建依赖、云端服务或账号凭证读取。

## 5. 验证证据

- `npm run check`：JavaScript 语法、Manifest 解析和入口文件检查通过。
- `npm test`：43 项测试通过，包含笔记、稍后顺序、反馈幂等、统计聚合、提醒时间与暂停/完成抑制。
- Chromium 扩展端到端验证：生成 5 道今日任务；详情笔记可持久化；稍后任务移至末尾；反馈显示下次日期；21 个日历单元和 14 天预测均渲染；已完成、未来和空日期的明细一致，且可继续进入题目详情；提醒闹钟创建成功；控制台无错误。
- 390px 视口文档宽度与客户端宽度均为 390px，无横向溢出。
