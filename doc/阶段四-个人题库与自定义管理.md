# LeetCode 复习插件：阶段四个人题库与自定义管理

## 1. 阶段结论

阶段四 `T-301` 至 `T-310` 已于 2026-08-01 完成实现、自动化测试和个人本地 MVP 最小真实账号人工验收。个人题库使用独立扩展全页应用，弹窗保留账号同步摘要并提供“打开复习工作台”入口。

真实账号最小验收覆盖字段抽查、状态和重点修改、再次同步保护、加入复习及重载持久化，证据见[《真实账号最小人工验收记录》](./真实账号最小人工验收记录-2026-08-01.md)。未逐项留证的完整发布验收清单仍不勾选。

## 2. 实现范围

### 2.1 状态版本迁移

- 根状态版本从 `1` 升级到 `2`。
- 读取旧状态时为设置、复习卡片和计划字段补默认值，并立即持久化迁移结果。
- 迁移不重命名已有字段，不覆盖笔记、历史、重点、掌握程度或用户状态。

### 2.2 题库查询

`src/core/library.js` 提供不依赖 `chrome` 的纯函数：

- 按中文标题、英文标题、展示题号和来源题号搜索；
- 按是否参与复习、五种复习状态、四档掌握程度、难度、标签和逾期状态组合筛选；
- 按完成时间、最近复习时间和下次复习时间稳定排序；
- 缺失日期始终排在有效日期之后；
- 后台分页返回，每页最多 100 条，工作台默认每页 30 条。

### 2.3 状态操作

- 单题和批量操作共用同一状态转换函数。
- 支持加入、移出、暂停、毕业、忽略、恢复和重点切换。
- 暂停保存距离到期的剩余天数；恢复时从恢复日继续计算。
- 批量操作先验证全部题目，任一转换无效则整批不保存。
- 后台通过单一操作队列串行化同步与题库写入，避免并发覆盖。

### 2.4 新题规则

设置支持“进入待确认”和“自动加入复习”。同步引擎只在创建新题时读取该设置，已有题目的手动状态、FSRS 数据、复习历史和笔记继续完整保留。

## 3. 页面能力

`src/app/` 新增完整工作台：

- “我的题库”展示题号、标题、难度、标签、完成时间、状态、掌握程度和下次复习时间；
- 提供组合筛选、搜索、排序、分页和本页全选；
- 单题操作根据当前状态只展示允许的目标状态；
- 批量毕业、忽略和移出前显示影响数量并要求确认；
- 390px 手机和 1440px 桌面视口下无横向溢出。

## 4. 验证

- `npm run check`：通过。
- `npm test`：阶段四完成时纳入完整测试集并通过。
- 浏览器注入假数据检查：桌面和手机视口的题库列表、长标题、筛选区和操作区均无横向溢出。
