# LeetCode 复习插件预期效果文档

## 1. 文档目的

本文档用于描述 LeetCode 复习插件完成后的预期使用效果，明确产品目标、核心功能、用户流程和验收标准。本文档暂不涉及技术选型、系统架构、接口设计和具体实现方式。

## 2. 产品定位

这是一款面向 LeetCode 刷题用户的复习管理插件。插件读取用户账号中的做题记录，将已经完成的题目整理成个人题库，并结合做题时间、掌握程度和复习表现，为用户生成每天可执行的复习任务。

插件的核心价值不是帮助用户继续堆积做题数量，而是减少“做过但忘了”的情况，让用户知道：

- 今天应该复习哪些题；
- 为什么这些题需要复习；
- 哪些题已经掌握，哪些题仍然薄弱；
- 接下来一段时间的复习压力如何；
- 哪些题不需要进入复习计划。

## 3. 目标用户

主要用户是已经在 LeetCode 上持续刷题，希望通过系统复习提高记忆效果的人，包括：

- 准备算法面试，需要在有限时间内复习高频题的用户；
- 已经完成一定数量题目，但容易遗忘解法的用户；
- 希望建立长期刷题习惯，并跟踪掌握情况的用户；
- 想自主决定复习范围，而不是完全服从自动推荐的用户。

## 4. 核心使用流程

### 4.1 首次使用

1. 用户授权插件读取自己的 LeetCode 刷题记录。
2. 插件同步已完成题目，并显示同步结果，包括题目总数、最近做题时间和可加入复习的题目数量。
3. 用户设置每日可用于复习的时间或题目数量。
4. 用户可选择复习目标，例如面试冲刺、日常巩固或仅复习错题与薄弱题。
5. 插件生成首份复习计划，并允许用户在启用前检查和调整。

### 4.2 每日复习

1. 用户打开插件后，首页直接显示“今日复习”。
2. 今日任务按照优先级排列，并展示预计耗时。
3. 用户进入题目详情，查看题目基本信息、历史完成时间、历史复习情况和当前掌握状态。
4. 用户前往 LeetCode 完成复习，回到插件记录本次复习结果。
5. 插件根据用户反馈调整该题的下次复习时间。
6. 今日任务完成后，插件展示完成情况和后续复习安排。

### 4.3 计划调整

用户可以随时修改每日复习量、暂停计划、跳过当天任务，或调整单道题是否参与复习。计划变化后，插件应自动重新分配后续任务，避免某一天突然堆积过多题目。

## 5. 核心功能的预期效果

### 5.1 刷题记录同步

插件能够将用户的 LeetCode 做题记录转换为清晰的个人题库。每道题至少应呈现：

- 题目名称与编号；
- 难度；
- 题目标签；
- 最近完成时间；
- 当前是否加入复习；
- 当前掌握状态；
- 下次计划复习时间。

同步过程应明确展示状态。同步成功时告知新增或更新了多少道题；同步失败时说明影响范围，并允许用户重新同步。重复同步不应产生重复题目。

### 5.2 个性化复习安排

插件根据题目的遗忘风险和用户可投入的时间安排复习，而不是简单地按做题日期平均分配。

预期安排效果如下：

- 刚完成且尚未巩固的题目，在较短时间内安排首次复习；
- 用户反馈“不会”或“很模糊”的题目，更早再次出现；
- 用户多次反馈“熟练”的题目，逐步延长复习间隔；
- 长期未复习的旧题，根据优先级逐步加入计划；
- 临近面试时，可提高高频题、薄弱题和用户指定题目的优先级；
- 每日任务量应符合用户设置的时间或题数上限；
- 未完成任务应合理顺延，不能无限累积并失去可执行性。

每个推荐任务都应提供简短、可理解的推荐原因，例如“首次复习”“上次未掌握”“长时间未复习”或“用户设为重点”。

### 5.3 用户自定义是否复习

用户对复习范围拥有最终决定权。插件应支持：

- 将单道题加入或移出复习计划；
- 批量设置某类题目是否参与复习；
- 将题目标记为重点题，提高复习优先级；
- 暂停某道题的复习，并在需要时恢复；
- 将已经完全掌握的题目标记为“已毕业”；
- 对不想再看到的题目设置为忽略；
- 随时撤销或修改上述状态。

自动同步到的新题可以根据用户偏好自动加入复习，也可以先进入“待确认”列表，由用户决定是否加入。

### 5.4 复习结果反馈

每次复习后，用户可以用低成本方式评价掌握程度，建议采用四档反馈：

- 不会：无法独立完成，几乎忘记解法；
- 模糊：知道大致方向，但无法顺利写出；
- 掌握：能够独立完成，仍需正常巩固；
- 熟练：能够快速说明思路并正确完成。

用户还可以记录简短笔记，例如错误原因、关键思路、容易遗漏的边界条件和需要再次关注的知识点。反馈完成后，插件立即显示预计下次复习时间，让计划变化可感知。

### 5.5 个人题库

个人题库用于集中查看所有同步题目，并支持按以下条件查找和筛选：

- 是否加入复习；
- 掌握状态；
- 难度；
- 标签；
- 最近完成或复习时间；
- 是否为重点题；
- 是否逾期；
- 关键词搜索。

题库应支持批量操作，方便用户快速整理大量历史题目，而不需要逐题修改。

### 5.6 复习进度与统计

插件应提供能帮助用户调整行为的统计信息，而不只是展示做题总数。预期包括：

- 今日和本周复习完成率；
- 各掌握状态的题目数量；
- 即将到期和已经逾期的题目数量；
- 不同难度、标签下的掌握分布；
- 连续完成复习的天数；
- 一段时间内从“不会”提升到“掌握”或“熟练”的题目数量；
- 未来若干天的预计任务量。

统计结果应帮助用户发现薄弱领域和计划压力，而不是通过复杂图表增加理解成本。

## 6. 主要页面的预期效果

### 6.1 今日复习

作为默认首页，集中展示：

- 今日计划题数与预计耗时；
- 已完成进度；
- 按优先级排列的题目列表；
- 每道题的推荐原因和上次掌握状态；
- 开始复习、稍后处理、跳过和调整状态等操作。

用户应能在打开插件后的几秒内明确下一步要做什么。

### 6.2 我的题库

展示全部同步题目，提供搜索、筛选、排序和批量管理。题目的复习状态应清晰可见，用户可以直接决定是否复习、设为重点或标记为已毕业。

### 6.3 复习日历

以日历或时间线形式展示已完成任务、逾期任务和未来安排。用户修改每日任务上限后，可以看到未来计划如何重新分布。

### 6.4 数据概览

展示复习完成情况、掌握程度变化、薄弱标签和未来任务压力。数据应优先回答“我是否在进步”和“接下来应该关注什么”。

### 6.5 设置

用户可在设置中管理：

- LeetCode 账号与同步状态；
- 自动同步频率；
- 每日复习时间或题目上限；
- 每周可复习日期；
- 新完成题目的默认处理方式；
- 提醒时间与提醒开关；
- 数据导出、清除和账号解绑。

## 7. 关键状态与异常场景

插件应对以下情况给出明确反馈：

- 账号未连接或授权已失效；
- 网络异常导致同步失败；
- LeetCode 记录暂时无法读取；
- 没有可复习题目；
- 今日任务已经全部完成；
- 用户连续多日未复习；
- 未完成任务超过每日容量；
- 题目状态发生变化或已不可访问；
- 同一账号在多个设备上产生了状态变化。

异常不应导致用户已有的复习记录丢失。对于无法自动处理的情况，应说明原因、影响和可执行的下一步操作。

## 8. 提醒体验

用户可以开启每日复习提醒。提醒内容应简洁并具有行动价值，例如今日待复习题数、预计耗时和最优先的一道题。

提醒应满足以下要求：

- 用户可自由开启、关闭和设置时间；
- 当日任务完成后不再重复提醒；
- 用户暂停计划期间不发送复习提醒；
- 避免高频催促造成干扰；
- 点击提醒后直接进入今日复习页面。

## 9. 隐私与用户控制

插件只应读取实现复习功能所必需的信息，并明确告知用户读取了什么、用于什么目的。用户应能够：

- 查看当前账号连接和同步状态；
- 手动触发同步；
- 导出自己的复习记录与笔记；
- 删除插件保存的个人数据；
- 解绑 LeetCode 账号；
- 关闭非必要的数据统计。

插件不应在未经用户确认的情况下公开刷题记录、复习进度或个人笔记。

## 10. 产品验收标准

首个可用版本达到以下效果，即可认为核心体验成立：

1. 用户能够连接 LeetCode 账号，并看到自己的历史已完成题目。
2. 同一题目不会因多次同步而重复出现。
3. 用户能够设置每天的复习容量，并获得对应的今日任务。
4. 用户能够明确查看每道题被安排复习的原因。
5. 用户能够将任意题目加入或移出复习计划。
6. 用户能够完成一次复习并记录掌握程度。
7. 复习反馈能够影响该题后续的复习时间。
8. 用户未完成当天任务时，后续计划能够重新分配且不明显超出每日容量。
9. 用户能够搜索、筛选和批量管理个人题库。
10. 用户能够查看近期完成情况、掌握状态和未来任务量。
11. 同步或网络异常时，插件提供可理解的提示，并保留已有数据。
12. 用户能够导出或删除自己的复习数据，并解绑账号。

## 11. 首个版本暂不追求的内容

为了保证核心复习流程清晰，首个版本可以暂不包含：

- 在线代码编辑器或判题系统；
- 自动生成完整题解；
- 用户排名、社区动态或公开排行榜；
- 复杂的游戏化成长体系；
- 多个算法平台的统一同步；
- 基于用户代码质量的自动评分；
- 面向团队或培训机构的管理功能。

这些能力可以在账号同步、复习安排、自定义题库和反馈闭环稳定后再评估。

## 12. 预期最终体验

用户每天打开插件后，不需要重新思考应该复习什么，只需根据今日任务开始行动；同时，用户始终可以调整复习范围和节奏，不会被自动计划绑架。

经过一段时间使用后，用户能够清楚看到哪些题已经掌握、哪些知识点仍然薄弱，以及未来几天需要投入多少时间。插件最终应成为连接“做过一道题”和“真正掌握一道题”之间的复习工具。
