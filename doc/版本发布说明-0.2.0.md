# 版本发布说明 0.2.0

## 本版本

- 新增连接账号前的数据读取说明和明确同意。
- 新增题库、复习记录、计划和笔记 JSON 导出。
- 新增输入 DELETE 的不可逆个人数据删除。
- 新增解绑保留数据后的本地访问锁。
- 新增状态备份和主状态损坏恢复。
- 新增操作失败重试入口和错误信息脱敏。
- 新增非必要统计开关。
- 新增完整数据流、边界、最小权限、无障碍静态检查和 Edge 目标尺寸冒烟验证。

## 验证

执行 npm run check、npm test 和 npm run smoke。当前自动化测试共 59 项，全部通过；Edge 冒烟验证覆盖 1440px、390px 和 368px 视口，无横向溢出或运行时异常。

## 限制

GraphQL 仍是力扣网站内部接口，字段可能变化。近期通过时间不能代表完整历史首次通过时间。当前不支持云端多设备复习状态同步、数据导入和公开商店发布。
