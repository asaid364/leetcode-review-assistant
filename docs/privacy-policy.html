LeetCode 复习助手隐私政策

版本：0.2.0；最后更新：2026-08-14

概述

LeetCode 复习助手是一款浏览器扩展，用于帮助用户基于力扣中国站（leetcode.cn）的已通过题目建立本地题库、生成复习计划和管理复习进度。

本扩展不是力扣中国站（leetcode.cn）的官方产品，也不代表与力扣中国站存在从属、授权或合作关系。用户使用本扩展时仍应遵守力扣中国站的服务条款。

读取的数据

连接账号前，扩展会向用户展示数据使用说明，并要求用户同意读取范围。扩展只读取：

  • 力扣中国站当前登录账号的最小标识，包括用户 slug、用户名和展示名称。
  • 已通过题目的题号、标题、难度、标签、付费标记和可获得的近期完成时间。

数据用途

上述数据仅用于：

  • 建立当前浏览器内的个人题库。
  • 生成每日复习任务和后续复习计划。
  • 计算复习进度、完成记录和题目掌握状态。
  • 在用户主动点击时打开对应的力扣题目页面。

不会读取或保存的数据

本扩展不提供密码输入框，不读取或保存密码、Session Cookie、CSRF 值、访问令牌、提交代码和运行结果。

数据存储与传输

复习状态、反馈历史、计划、设置和个人笔记保存在当前浏览器的 chrome.storage.local 中。本扩展不提供开发者服务器，不会把用户题库、笔记、复习历史或账号标识上传给开发者，也不向第三方分析服务发送数据。

本扩展会调用 leetcode.cn 的后端 GraphQL 接口，用于在用户主动连接或同步时读取其已通过题目数据。该请求发生在用户已登录的 leetcode.cn 浏览器会话中。

用户控制

用户可以在扩展内主动导出 JSON 数据、解绑账号或删除个人数据。删除个人数据需要二次确认，删除后本地题库、复习历史、笔记、计划、同步历史和账号关联将被清除，且不可由扩展恢复。

用户选择解绑并保留数据后，数据会被锁定，只有重新连接原账号后才能查看。

权限说明

  • storage：将题库、复习计划、设置、笔记和相关状态保存在当前浏览器本地。
  • alarms：安排自动同步和每日复习提醒。
  • notifications：到达提醒时间且今日任务未完成时显示浏览器通知。
  • tabs：查找已打开的 leetcode.cn 标签页，打开复习工作台或题目页面。
  • scripting：当 leetcode.cn 页面尚未注入内容脚本时，注入本扩展自己的脚本以完成用户主动同步。
  • https://leetcode.cn/*：仅在力扣中国站页面内读取当前登录用户主动同步所需的题目数据。
