# LeetCode 复习助手使用说明

## 主要功能

- 同步 leetcode.cn 已通过题目，建立本地个人题库。
- 根据复习计划生成每日任务，并按掌握程度安排下次复习。
- 支持题目搜索、筛选、批量管理、重点标记、笔记和复习历史。
- 支持每日提醒、JSON 数据导出、账号解绑和个人数据删除。

## 首次使用

1. 在 Chrome 或 Edge 的扩展管理页开启开发者模式，加载项目根目录。
2. 打开 leetcode.cn 并登录目标账号。
3. 打开扩展，阅读数据使用说明并点击同意。
4. 连接当前账号，执行立即同步。
5. 进入复习工作台，在计划设置中选择每日题数或预计分钟数。

## 日常复习

今日复习页按优先级列出任务。每道题可以打开力扣、查看历史和笔记，并提交不会、模糊、掌握或熟练反馈。反馈成功后会立即显示下次复习时间。稍后处理会保留任务，跳过不会计入完成。

## 题库和计划

我的题库支持搜索、筛选、分页、批量状态调整和重点标记。计划设置支持每日容量、复习目标、新题处理方式和每日提醒。所有用户手动状态、笔记和历史都会在同步时保留。

## 数据控制

计划设置的数据控制区支持导出 JSON。删除个人数据需要输入 DELETE 二次确认，会删除题库、复习历史、笔记、计划、同步历史和账号关联，且不可恢复。仅解绑并保留会锁定数据，重新连接同一账号后恢复访问。
